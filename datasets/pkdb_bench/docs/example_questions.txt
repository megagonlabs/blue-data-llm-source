LLM as DB
—------------
What are the types of queries?

Fundamentally, we want an underlying system that breaks down the query for performance reasons, including accuracy and scale of data. Queries should be expected to return multiple attributes with varying degrees of scale and accuracy.

For example, consider a query where we ask for top 5 tallest buildings in every state, city in the US. It is expected that well-known tall buildings in large cities are pretty well documented and as such have higher confidence in LLMs parametric knowledge.

It is also worth noting that since the result set is pretty big it makes sense to break down the query by state, get cities in each state, and then go about querying tallest buildings.
